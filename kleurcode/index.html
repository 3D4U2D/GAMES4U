Kleurcode

Zo speel je Kleurcode

Er ligt een geheime code van gekleurde knikkers. Kraak hem in zo weinig mogelijk pogingen.

Tik op een knikker onderaan om hem in het eerstvolgende gaatje te leggen. Tik op een gaatje om het te kiezen of leeg te maken. Is de rij vol, tik dan op Controleer.

= goede kleur op de goede plek
= goede kleur, maar op een andere plek

De pinnetjes zeggen niet wélke knikker goed is: dat is de puzzel! Elke kleur heeft ook een eigen symbool, zodat je ze altijd uit elkaar houdt.

Dagcode: elke dag één nieuwe code (niveau Normaal). Vrij spelen: kies zelf je niveau.
